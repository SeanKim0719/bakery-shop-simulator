# 로드맵

MVP는 빵 5종, 오븐 2대, 선반 4개, 손님 성향 3종, 발주·굽기·진열·계산·정산으로 이어지는 하루 사이클, 미스터리 박스와 레시피 도감, 세이브다. 공기업 준비와 병행하므로 하루 1~2시간 기준 8주로 잡는다.

각 단계 끝에 "이 상태로도 보여줄 수 있는" 빌드를 태그로 남겨, 시험 기간에 개발이 멈춰도 손실이 없게 한다.

## MVP 일정

### 1~2주차 — 1인칭 조작과 상호작용

- [ ] Unity 프로젝트 생성, Git LFS·.gitignore 설정
- [ ] PlayerController (이동, 시점)
- [ ] Raycast 상호작용, `IInteractable`, 상호작용 안내 HUD
- [ ] 물건 집기·놓기, 박스 운반
- 완료 기준: 회색 박스 매장에서 박스를 들어 선반에 올리는 조작감이 자연스럽다

### 3~4주차 — 핵심 루프 회색 박스

- [ ] TimeManager, GameEvents
- [ ] 발주 PC 앱, 배송 박스 스폰·개봉
- [ ] 오븐과 품질 판정
- [ ] 선반 슬롯 스냅, 가격표
- [ ] NavMesh 손님 (구매만)
- [ ] 계산대 결제 흐름
- [ ] 정산 화면
- 완료 기준: 하루가 처음부터 끝까지 돈다

### 5~6주차 — 구조와 깊이

- [ ] 미스터리 박스 (LootTable, 천장, 분포 테스트)
- [ ] 레시피 도감 (조합 판정, 도감 UI)
- [ ] 데이터 드리븐 정리 (RecipeData, ProductData, CustomerProfile)
- [ ] 손님 FSM 이탈·평판
- [ ] 시세 대비 구매 확률
- [ ] 세이브/로드
- 완료 기준: 새 빵을 에셋 추가만으로 넣을 수 있다

### 7~8주차 — 마감

- [ ] 무료 로우폴리 에셋으로 매장 아트
- [ ] 사운드, 개봉 연출
- [ ] 프로파일링과 최적화
- [ ] 빌드, 플레이 영상, README 완성

## MVP 이후 선택 과제

- 매장 확장·가구 배치 (BuildMode, 런타임 NavMesh)
- 수요 변동·통계 그래프
- 직원 고용 (AI 점원)
- 서버 관심사를 살린 간단한 랭킹 서버 또는 클라우드 세이브
