## 새 기록 작성법

`NNNN-짧은-제목.md` 파일을 만들고 아래 형식을 따른다.

```markdown
# NNNN. 제목

- 상태: 제안 / 확정 / 폐기 (대체: NNNN)
- 날짜: YYYY-MM-DD

## 상황
## 선택지
## 결정
## 이유
## 결과와 트레이드오프
```
