# 12. 콘텐츠 수치표

> 이 문서는 [`content.json`](../../Assets/_Project/Data/content.json)에서 자동으로 만든다. 직접 고치지 말고 `content.json`을 고친 뒤 `python3 Tools/docs/content_tables.py`를 실행한다.

게임의 모든 수치는 `content.json` 한 파일에 있다. 에디터 메뉴 **BakeryShop → 콘텐츠 가져오기**가 이 파일을 읽어 ScriptableObject 에셋의 수치를 채우고, 아이콘·프리팹 같은 외형은 에셋의 인스펙터에서 따로 연결한다 ([ADR 0009](../decisions/0009-content-json-pipeline.md)). 밸런스 시뮬레이터도 같은 파일을 읽는다.

- 모든 레시피 공통: 다 익은 뒤 8초 안에 꺼내면 완벽, 30초를 넘기면 탄다. 굽는 시간의 50%가 지나야 꺼낼 수 있다 (덜 익음).
- 비밀 레시피의 재료비에는 핵심 재료가 빠져 있다.
- 보관 N일: 구운 날을 0일로 세어 N일차까지 팔 수 있고, 그날 정산 때 남아 있으면 폐기된다.
