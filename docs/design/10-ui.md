# 10. 화면과 UI

화면은 **HUD 하나, 패널 5종, 월드 표시 3종**으로 이루어진다. 패널은 한 번에 하나만 열리고, 열고 닫는 일과 입력 모드 전환은 `PanelHost` 한 곳에서 한다.

## 공통 규칙

| 규칙 | 내용 |
| --- | --- |
| 기술 | uGUI + TextMeshPro. 한글 글꼴은 Pretendard(OFL)로 TMP 동적 폰트 에셋을 만든다 |
| 해상도 | 기준 1920×1080, `CanvasScaler`의 Scale With Screen Size (match 0.5). 1280×720에서 깨지지 않게 |
| 패널 열기 | `PanelHost.Open(panel)` → 입력 모드 UI, 커서 풀림, 상호작용 안내 숨김 |
| 패널 닫기 | Esc 또는 닫기 버튼 → `PanelHost.Close()` → 입력 모드 Gameplay, 커서 잠김 |
| 시간 | 패널이 열려도 시간은 흐른다. 일시정지 메뉴와 정산 리포트만 예외 |
| 동시 표시 | 패널은 한 번에 하나. 다른 패널을 열면 이전 패널은 닫힌다 |
| 숫자 | 금액은 `152,300원`처럼 쉼표와 "원"을 붙인다 (`MoneyFormat.Won`) |
| 만드는 방법 | 그레이박스 단계에서는 에디터 빌더 코드(`ShopUiBuilder`)로 씬에 생성한다. 아트 단계에서 프리팹으로 바꾼다 |

Esc의 동작: 패널이 열려 있으면 패널을 닫고, 아니면 일시정지 메뉴를 연다.

| 요소 | 내용 | 갱신 방식 |
| --- | --- | --- |
| 날짜·단계 | `N일차 · 준비 중 / 영업 중 / 마감 / 정산` | `DayPhaseChanged` 이벤트 |
| 시계 | 영업 시계 (준비 중에는 09:00 고정) | 매 프레임 `TimeService` 읽기 |
| 돈 | 잔액. 변할 때 `+3,600` 같은 변화량이 잠깐 뜬다 | `MoneyChanged` |
| 평판 | 별 5개 (반 개 단위) | `ReputationChanged` |
| 레벨 | 레벨, 경험치 막대, 현재/다음 기준 | `XpGained`, `LevelUp` |
| 목표 | 지금 할 일 최대 3줄 (아래 "목표 리스트") | `ObjectiveTracker` |
| 조준점·안내 | 화면 중앙 점, 그 아래 `[E] 행동` | `Interactor.OptionChanged` (M1에서 구현) |
| 알림 | 2.5초 동안 뜨는 한 줄. 여러 개면 차례로 | 아래 "알림" 표 |
| 빈 트레이 | `빈 트레이 n/전체` | `TraysChanged` |
| 빵 냄새 | 남은 시간. 없으면 숨김 | 매 프레임 읽기 |

## 오븐 패널

오븐을 빈손으로 바라보고 E. 오븐이 비어 있으면 **굽기** 탭이, 굽는 중이어도 **실험** 탭은 쓸 수 있다.

```
┌─ 오븐 1 ───────────────────────────────────────────────────┐
│ [ 굽기 ]  [ 실험 ]                                         │
│ ┌ 레시피 ──────────────┐  ┌ 크루아상 ───────────────────┐ │
│ │   식빵          4개  │  │ 밀가루  2   (보유 20)       │ │
│ │   단팥빵        6개  │  │ 버터    3   (보유 9)        │ │
│ │ ▶ 크루아상      6개  │  │ 굽는 시간   45초            │ │
│ │   소금빵   재료 부족 │  │ 시세        3,000원 × 6개   │ │
│ └──────────────────────┘  │ 빈 트레이   2 / 3           │ │
│                           │           [ 굽기 시작 ]     │ │
│                           └─────────────────────────────┘ │
│                                              [Esc] 닫기    │
└────────────────────────────────────────────────────────────┘
```

- 재료가 모자라거나 빈 트레이가 없으면 **굽기 시작**이 꺼지고 이유를 표시한다.
- 굽기를 시작하면 패널이 닫힌다 (바로 다른 일을 하러 가도록).

실험 탭:

```
┌─ 오븐 1 ───────────────────────────────────────────────────┐
│ [ 굽기 ]  [ 실험 ]                                         │
│ 핵심 재료   [ 아몬드 ▼ ]   (보유 1, 실험해도 줄지 않음)    │
│ 힌트        평범한 크루아상에 고소한 무언가를 더하면…      │
│ 다른 재료   [ 밀가루 ] [ 버터 ]          ← 2칸을 채운다    │
│   밀가루 20  버터 9  설탕 3  우유 6  달걀 3  팥앙금 6  소금 0  초콜릿 0 │
│                                        [ 실험하기 ]        │
│ 실험 기록                                                  │
│   밀가루 + 우유     → 1개 맞음                             │
│   밀가루 + 팥앙금   → 1개 맞음                             │
└────────────────────────────────────────────────────────────┘
```

## PC 패널

계산 구역의 PC를 바라보고 E. 탭 다섯 개.

| 탭 | 내용 | 주요 동작 |
| --- | --- | --- |
| **발주** | 상품 목록 (이름, 내용물, 가격, 보유량), 수량 선택, 장바구니 합계. 아래에 **재료 판매** | 주문하기 → 돈 차감, 20초 뒤 배송 |
| **가격** | 빵별 시세, 현재 판매가, `-` `+` 버튼(100원), 어제의 "비싸서 안 산 횟수" | 판매가 변경 (즉시 적용) |
| **도감** | 레시피 10칸. 숨김 / 힌트 / 발견 상태, 발견 수 | 읽기 전용 |
| **성장** | 레벨과 경험치, 살 수 있는 해금 목록 (레벨 부족은 회색), 가격 | 구매 → 즉시 적용 |
| **리포트** | 지난 날들의 일일 리포트 다시 보기, 마감 단계에는 **마감 정산** 버튼 | 정산 시작 |

```
┌─ PC ───────────────────────────────────────────────────────────────┐
│ [ 발주 ] [ 가격 ] [ 도감 ] [ 성장 ] [ 리포트 ]        152,300원    │
│ ┌ 상품 ───────────────────────────────────────┐ ┌ 장바구니 ─────┐ │
│ │ 밀가루 10개        6,000원   보유 4   [-] 2 [+] │ │ 밀가루 ×2  12,000 │ │
│ │ 버터 10개         15,000원   보유 9   [-] 1 [+] │ │ 버터 ×1    15,000 │ │
│ │ 농장 직송 미스터리 박스 12,000원      [-] 1 [+] │ │ 박스 ×1    12,000 │ │
│ │ 초콜릿 5개  (레벨 4에 열림)                    │ │ 합계       39,000 │ │
│ └─────────────────────────────────────────────┘ │   [ 주문하기 ]  │ │
│ [ 재료 판매 ]                                    └───────────────┘ │
└────────────────────────────────────────────────────────────────────┘
```

## 계산 패널

손님이 계산대에 빵을 올리면 빵을 하나씩 바라보고 E로 스캔한다 (패널 없이 월드에서). 전부 스캔하면 결제 패널이 자동으로 열린다.

카드:

```
┌─ 카드 결제 ───────────────┐
│ 합계          7,500원     │
│ 입력          [   7,500 ] │
│   [7] [8] [9]             │
│   [4] [5] [6]             │
│   [1] [2] [3]             │
│   [지움] [0] [00]         │
│          [ 결제 ]         │
└───────────────────────────┘
```

현금:

```
┌─ 현금 결제 ─────────────────────────────┐
│ 합계          7,500원                   │
│ 받은 돈      10,000원                   │
│ 거스름돈      2,500원   ← 설정에서 끌 수 있음 │
│ 건넬 돈       2,000원                   │
│ [50,000] [10,000] [5,000] [1,000]       │
│ [500] [100]            [ 다시 ]         │
│                        [ 건네기 ]       │
└─────────────────────────────────────────┘
```

- 키보드 숫자 키와 Enter로도 입력할 수 있다.
- 결제 패널은 Esc로 닫을 수 없다 (손님을 세워 둔 채 떠날 수 없게). 금액을 잘못 넣어 거부되면 패널이 흔들리고 입력이 초기화된다.
- 결제가 끝나면 패널이 닫히고 다음 손님이 온다.

## 정산 리포트

마감 단계에 PC의 **마감 정산**을 누르면 전체 화면으로 뜬다. 이때 하루 마무리 처리와 자동 저장이 끝나 있다.

```
┌─ 3일차 정산 ───────────────────────────────────────────────────────┐
│ 매출            105,300원        손님  방문 21 · 결제 20            │
│ 발주 지출       -27,000원              빈손으로 떠남 1 · 줄에서 떠남 0 │
│ 임대료          -15,000원        평판  ★★★☆☆  (+18)              │
│ 계산 실수            0원        경험치 +68  (Lv.3까지 23)          │
│ ─────────────────────────                                         │
│ 순이익          +63,300원        잔액  215,600원                   │
│                                                                    │
│ 빵별            판매   놓친 수요   비싸서 안 삼   폐기   내일 할인  │
│ 크루아상          11       2           0          0        3       │
│ 식빵               8       0           1          0        2       │
│ 단팥빵             9       0           0          1        0       │
│ 소금빵             4       3           0          0        0       │
│                                                                    │
│ 한 줄 조언  소금빵을 찾는 손님 3명이 그냥 돌아갔습니다.            │
│                                                  [ 다음 날 ]       │
└────────────────────────────────────────────────────────────────────┘
```

**한 줄 조언**은 리포트에서 가장 큰 문제 하나를 문장으로 알려준다. 우선순위: 줄에서 떠난 손님 3명 이상 → 놓친 수요가 가장 많은 빵 → 비싸서 안 산 횟수가 판매보다 많은 빵 → 폐기가 5개 이상 → 없으면 칭찬.

## 월드 표시

| 대상 | 표시 | 내용 |
| --- | --- | --- |
| 오븐 | 오븐 위 진행 막대와 남은 시간 | 굽는 중 회색 → 완벽 구간 금색 → 보통 구간 주황 → 탐 검정. 다 익는 순간 "띵!", 타기 5초 전부터 경고음 |
| 진열대 칸 | 칸 앞 가격표 | 빵 이름, 표시가, 수량 `4/6`. 하루 지난 빵이 있으면 "할인" 표시 |
| 손님 | 머리 위 말풍선 | 찾는 빵이 없을 때 그 빵 아이콘과 "없네…", 비쌀 때 "비싸다", 인내심 30% 이하면 빨간 "!" |
| 잠긴 가구 | 반투명 + 자물쇠 | 바라보면 `진열대 3 · 레벨 2 · 60,000원 (PC의 성장 탭에서 구매)` |

| 줄에서 손님이 떠남 | 기다리던 손님이 그냥 돌아갔습니다 |
| 영업 종료 | 영업이 끝났습니다. 남은 손님을 보내고 PC에서 정산하세요 |
| 지원금 | 소상공인 지원금 12,000원이 들어왔습니다 |

## 목표 리스트 (온보딩)

별도의 튜토리얼 화면 없이, HUD의 목표가 다음 할 일을 안내한다. 목표는 순서대로 하나씩 열리고, 조건이 되는 이벤트가 발생하면 완료된다.

| 순서 | 목표 문구 | 완료 조건 |
| --- | --- | --- |
| 1 | 오븐에서 빵을 구워 보세요 | `BakingStarted` |
| 2 | "띵!" 소리가 나면 바로 꺼내세요 | `BakingCollected` |
| 3 | 트레이를 들고 진열대에 올리세요 | `ShelfChanged` (진열) |
| 4 | 문 옆 팻말을 돌려 영업을 시작하세요 | `DayPhaseChanged` → 영업 |
| 5 | 손님 3명을 계산하세요 (n/3) | `SaleCompleted` 3회 |
| 6 | 영업이 끝나면 PC에서 정산하세요 | `DaySettled` |
| 7 | PC에서 재료를 주문하세요 | `OrderPlaced` |
| 8 | 레벨 2가 되면 미스터리 박스를 주문하세요 | `OrderPlaced` (박스) |
| 9 | 박스를 창고로 가져가 열어 보세요 | `BoxOpened` (박스) |
| 10 | 핵심 재료로 실험해 비밀 레시피를 찾으세요 | `RecipeDiscovered` |
| 11 | 동네 맛집이 되세요: 레벨 5, 비밀 레시피 2종 | 데모 목표 달성 |

완료한 순서는 세이브에 저장한다. 이어하기에서는 완료하지 않은 첫 목표부터 보여준다.

## 타이틀과 일시정지

| 화면 | 항목 |
| --- | --- |
| 타이틀 | 새 게임 / 이어하기 (세이브가 있을 때) / 데모 세이브로 시작 / 종료 |
| 일시정지 (Esc) | 계속하기 / 설정 (마우스 감도, 소리 크기, 거스름돈 표시) / 타이틀로 (오늘 진행은 저장되지 않는다는 안내) |

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD, 마우스 | 이동, 시점 |
| E 또는 좌클릭 | 상호작용 (들기, 내려놓기, 열기, 스캔 …) |
| G | 손에 든 것 떨어뜨리기 |
| Esc | 패널 닫기 / 일시정지 |
| 숫자 키, Enter, Backspace | 결제 패널 입력 |
